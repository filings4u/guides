SCREENINGS4U GUIDE RECORDER

Install the click-perfect recorder

The recorder is required for numbered click guides because it captures the exact control, click location, page URL, and screenshot for each step.

1
Download and unzip the recorder.
Use the button below, then extract the ZIP to a permanent folder on your computer.
2
Open your browser's Extensions page.
Chrome: chrome://extensions  •  Edge: edge://extensions
3
Turn on Developer mode.
Then choose Load unpacked and select the extracted recorder folder that contains manifest.json.
4
Reload guides.screenings4u.com.
The Guide Builder will automatically show the recorder as connected.

Important: Chrome and Edge do not allow a normal website to silently install an unpacked extension. The one-time Load unpacked step is required unless the extension is published to an extension store.
